# Contribution Guidelines

Thank you for helping improve **Awesome CS PhD Research Starter Resources**! This list aims to help pre-PhD and early-stage (Years 1–3) CS PhD students find high-quality, practical resources.

## What to Add

Good additions are resources that are:

- **Useful for early-stage researchers** — reading and writing papers, communicating research, research methods, PhD applications, or foundational ML/NLP learning.
- **High quality and widely recommended** — e.g., written by experienced researchers, faculty, or well-known communities.
- **Freely accessible** — or clearly marked if they require payment.
- **Actively maintained or timeless** — no broken or outdated links.

Please avoid self-promotion of low-effort content, paywalled course ads, or duplicates of existing entries.

## How to Contribute

1. Fork this repository.
2. Add your resource to the most relevant section in `README.md`.
3. Open a pull request with a short title, e.g., `Add <resource name>`.
4. In the pull request description, briefly explain why the resource is useful.

One pull request per resource (or a small group of closely related resources) is preferred.

## Formatting

Use this format for each entry:

```markdown
- [Resource Name](https://link-to-resource) by Author Name - One-sentence description ending with a period.
```

- Keep descriptions short (one sentence when possible).
- Use the author's name as it appears on the resource; omit `by ...` if there is no clear author.
- For courses, add the platform in parentheses, e.g., `(Coursera)`.
- Check that the link works and that the entry is not already listed.
- Keep entries within a section in a logical order; new entries can go at the end of the section.

## Suggesting a New Section

If your resource does not fit any existing section, open an issue describing the proposed section and a few example resources.

## Reporting Issues

Found a broken link or outdated information? Please [open an issue](../../issues) or submit a pull request with the fix.

## Code of Conduct

Please be respectful and constructive in all interactions. By contributing, you agree that your contributions will be released under the same license as this project ([CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)).
